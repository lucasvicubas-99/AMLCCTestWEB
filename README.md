# Web AML Centrifugal Casting · versión de pruebas

Web corporativa de AML Centrifugal Casting, S.L. (versión 6, con subpáginas).

## Páginas

- `index.html` — Inicio
- `capacidades.html` — Parque de máquinas y capacidades (fresado, torneado, mandrinado, soldadura)
- `calidad.html` — Ensayos, metrología y sistema de calidad
- `sectores.html` — Sectores
- `materiales.html` — Tabla de materiales y consulta
- `contacto.html` — Ferias y formulario de contacto

## Estructura

- `assets/` — fotos (WebP), vídeo de portada y recursos de ondas
- `vendor/` — motor que dibuja las páginas en el navegador (no editar)
